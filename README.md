영어, 술술 나오세요?

카페 주문도 입국 심사도, 가기 전에 먼저 말해 보세요. AI가 점원도 되고 심사관도 돼요. 내가 말할 때마다 어디가 틀렸는지 소리 하나까지 짚어 드려요.

- 발음이 틀린 단어는 내가 어떤 소리로 냈는지 보여 드려요
- 여행, 생활, 일 상황 미션이 96가지예요. 미션 밖에선 AI 친구 8명과 수다를 떨 수 있어요
- 영어, 일본어, 중국어 모두 단어마다 한글 발음이 붙어요
- 완전 초보라도 알파벳 소리부터 따라오면 돼요

카드 등록 없이 이메일만 있으면 7일 동안 무료로 써 볼 수 있어요.

## 다운로드

[speaking-lounge.com](https://www.speaking-lounge.com/ko#download)에서 받으시면 가장 쉬워요. 이 저장소의 [Releases](https://github.com/spintoai/speakinglounge-app/releases/latest)에서 바로 받으셔도 돼요.

- Windows: `.exe` 설치 파일(Windows 10이나 11, 64비트)
- Mac: `.dmg`(애플 실리콘, M 시리즈)

처음 켜면 앱이 음성 파일과 발음 채점 파일을 받아요.

폰과 태블릿 앱은 [App Store](https://apps.apple.com/kr/app/id6833050193)와 [Google Play](https://play.google.com/store/apps/details?id=com.spintoai.speakinglounge)에 있어요.

이 저장소는 Windows와 Mac 설치 파일을 올려 두는 곳이지만, 소스 코드는 공개하지 않아요.
